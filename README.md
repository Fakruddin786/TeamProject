# TeamProject - Team Task Management Application

A lightweight, collaborative task tracking web application built to demonstrate Git fundamentals, branching strategies, and merge conflict resolution.

## Project Description
TeamProject is a clean and intuitive task management application designed for agile teams. It serves as a practical demonstration of source control management, team collaboration workflows, and modern DevOps practices using Git.

## Project Description & Architecture
Updated on feature/task-completion branch by Developer 3: Enhanced task workflow model featuring interactive status toggling, complete/pending counters, dynamic DOM state management, and real-time task lifecycle handling.

## Features
- **Task Management Interface**: Clean and responsive user interface for managing daily tasks.
- **Task Creation**: Add tasks quickly with input validation.
- **Task Completion**: Toggle task completion status with visual status feedback.
- **Task Deletion**: Easily remove obsolete tasks from the list.

## Technologies Used
- **HTML5**: Semantic web markup structure.
- **CSS3**: Modern custom properties, flexbox, and responsive card design.
- **JavaScript (Vanilla ES6+)**: Client-side DOM manipulation and state management.
- **Git**: Distributed version control system and branch workflow.

## How to Run the Application
1. Clone or download this repository:
   ```bash
   git clone <repository-url>
   cd TeamProject
   ```
2. Open `index.html` in any modern web browser:
   - On Windows: double-click `index.html` or run:
     ```powershell
     Start-Process index.html
     ```
   - Alternatively, serve via Python or Node:
     ```bash
     python -m http.server 3000
     ```
3. Begin adding, completing, and managing your tasks.
